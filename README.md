# 日程 · WhaleLife 插件

按作息自动排出每天的时间表：到点生成、跨天补齐；聊天里问「今天有什么安排」「现在在干嘛」时读的是同一份计划。宿主提供 `context` 服务时，每一轮还会把「现在在做什么、下一项是什么」注入当前人格的上下文。

- 版本：以 `plugin.yaml` 为准
- 依赖：`tools` / `web` / `llm` / `models`；`context` 是可选的宿主服务，旧宿主没有时自动跳过
- 天气：独立子插件 `schedule/weather`，单独安装/更新
- 衣柜：独立子插件 `schedule/wardrobe`，单独安装/更新；父包不内置 sub，也不带服装图
- 数据：只写本插件 `data/`；时间按宿主本地时区

## 能做什么

1. **自动生成**：默认 07:00 生成今天和后面一天，可在设置页改；错过时间、跨天、隔天再打开都会补齐。
2. **按作息铺时间**：起床、早餐、通勤、正事、午饭、晚饭、运动、固定安排、睡前洗漱依次落位；中间空档用爱好池轮换填充。
3. **手动兜底**：日历里可以重排某天、加一项、改时间/标题/备注、标完成或跳过、删除。
4. **改动保护**：手动改过的计划标记 `edited`，自动重排不再覆盖；只有明确 `force` 才覆盖。
5. **可选 AI 润色**：用宿主已配置的对话模型，把「自由 · 看剧」这类空档换成更具体的安排；失败、超时或返回不合法时保留规则骨架，不阻塞生成。
6. **给模型 8 个工具**：读今天、读此刻、读多天、生成、编辑、异常日、待办池、人格日记；全部 `safe` 权限。
7. **天气子插件（独立安装）**：`schedule/weather` 走 Open-Meteo，不需要 API key；提供实时天气和未来 1–7 天预报，参与运动、户外空档和周末安排。子插件独立配置、独立启停。
8. **每轮上下文**：宿主有 `ctx.context.register()` 时，把当天计划的「正在 / 下一项 / 后面几项 / 天气调整」注入**当前人格**；不再限定某一个人格。没有该服务时聊天照常，模型仍可调用 `schedule_now`。
9. **衣柜子插件（独立安装）**：`schedule/wardrobe` 按当天日程、天气和季节给当前人格配穿搭；支持锁定、备选、喜欢/不喜欢/屏蔽、多日打包、画室参考和混搭提示。父包 `sub` 只声明关系，衣柜从商城单独安装，避免日程更新重复下载服装图。
10. **主动提醒**：起床、正事、通勤、三餐、运动、固定安排、旅行、睡觉前，按提前分钟通过已注册渠道发消息。默认走 QQ 的 `qq_send_message`；人格 ID 留空时使用宿主当前 Web 人格。
11. **节假日与假期**：可选内置中国 2026–2027 法定节假日和调休日；也支持自定义假期、学生寒暑假/春秋假、额外调休日，以及自定义周末日（默认周六、周日）。
12. **旅行安排**：周末和短假优先近处，长假期优先远途；地点池可写最少/最多天、指定日期段和备注；也可以指定目的地，或让 AI 从地点池里选。旅行按可用天数过滤，排不下就跳过；当天确实排入旅行时不再排常规运动。
13. **异常日**：日历当天可一键切换「生病 / 请假 / 加班 / 休息半天 / 休息」。只替换当天的临时配置，不改长期作息：生病和休息停正事与运动，请假停正事，休息半天只保留上午正事、下午从 12:00 起休息，加班把下班延到 21:00 并顺延晚饭；旅行同步暂停。随时可撤销恢复常规排程，模型也可以通过 `schedule_exception` 工具操作。
14. **周复盘**：日历页顶部展示本周完成率（含 pending 的口径和已处理口径）、完成/计划项、计划与完成时长、异常日数；下方有每日完成柱状、最常跳过项 Top 3、平均/最早/最晚入睡、旅行天数和运动完成次数，并对比上周完成率与完成项。
15. **重复规则**：正事、运动和固定安排都支持 `每周`（默认）、`双周 @基准日期`、`每月第 1–5 个周几`、`每月最后`，可用 `!2026-12-01` 排除某天。固定安排第二列直接写，例如 `双周 1,3,5 @2026-11-16`；正事/运动在设置页有单独的重复规则输入框。
16. **人格日记**：到点后由当天写日记的人格根据日程完成情况、天气和穿搭自动写一篇；支持自然记录、克制纪实、温柔陪伴、轻松俏皮、文学随笔、复盘反思六种文风，也可用自定义说明和示例。日记按人格隔离保存，只有写它的人格能通过 `schedule_diary` 读回；每轮只注入一条当天日记索引，不把全文塞进上下文。

## 默认值

插件开箱是一个中性的通用模板，不带任何个人或城市信息：

- 默认作息：上班模板（09:00–18:00，通勤 40 分钟），可在设置页套用「上学 / 自由职业」或全部手动改。
- 默认节假日：不启用内置表。中国用户可在设置页勾选「内置中国 2026–2027」；其他地区用自定义假期。
- 默认周末：周六、周日，可在设置页改成任意星期组合。
- 默认天气：城市和经纬度为空，首次使用需要到天气设置里按城市名定位，或手填坐标。
- 默认提醒：关闭；人格 ID 为空，开启后使用宿主当前人格。
- 默认人格日记：关闭；不预设人格、模型和文风；生成时间留空时按「睡前洗漱前 5 分钟」推算；不读取聊天原文。

## 安装

1. 在插件商店安装，或下载 Releases 里的 `schedule-<版本>.wlpkg.gz`。
2. 目录名必须是 `schedule`（manifest 要求 id 与目录同名）。
3. 重启 WhaleLife，或在控制台「插件管理」里重载。
4. 控制台出现「日程」后，打开设置页完成城市、作息和提醒等配置。
5. 需要天气或穿搭时，再分别安装「天气」`schedule-weather-<版本>.wlpkg.gz` 与「衣柜」`schedule-wardrobe-<版本>.wlpkg.gz`；父包不内置 sub，两者都从商店单独更新。

页面入口：

- 设置：`/plugins/schedule/settings`
- 日历：`/plugins/schedule/calendar`
- 天气设置：`/plugins/schedule/weather/settings`
- 衣柜设置：`/plugins/schedule/wardrobe/settings`

子插件更新后需要重启 WhaleLife，运行中的进程不会热扫 `sub/`。

## 设置项

| 分组 | 字段 | 说明 |
| --- | --- | --- |
| 自动生成 | 开关、生成时间、预生成天数、保留天数 | 生成时间后补齐今天 + 后面 N-1 天；历史只留最近 N 天 |
| 作息 | 起床、睡觉、起床后洗漱、早餐、单程通勤、睡前洗漱 | 睡觉早于起床按「次日」算，末尾到 `24:00` |
| 正事 | 开关、名称、地点、星期、开始、结束、重复规则 | 名称可写「上课」「上班」，自动加往返通勤；重复规则可空（每周） |
| 三餐 / 运动 | 各自开关、时间、时长；运动可指定星期和重复规则 | 午饭把正事切成上午/下午 |
| 固定安排 | 多行文本 | `标题 \| 星期/重复规则 \| 开始 \| 分钟 \| 地点`；星期写 `1-7` / `每天` / `工作日` / `周末`，可加 `双周 1,3,5 @2026-11-16`、`每月第2个 3`、`每月最后 5`、`!2026-12-01` |
| 爱好池 | 每行一个 | 空档按日期轮换，不会每天一样 |
| AI 润色 | 开关、模型、额外要求 | 模型只从宿主已有对话模型里选 |
| 人格日记 | 开关、人格、模型、生成时间、文风、是否参考天气/穿搭、自定义文风与示例 | 人格留空 = 只有一个角色时自动使用；模型留空 = 跟随人格模型；时间留空 = 按睡前洗漱推算 |
| 节假日与假期 | 开关、内置中国表、学生模式、周末日、自定义假期、额外调休日 | 自定义假期格式 `名称 \| 开始 \| 结束 \| 短假/长假/寒暑假` |
| 旅行 | 开关、周末/短假/长假、周末频率、AI 选择、指定目的地和日期段、旅行偏好、地点池 | 地点池格式 `地点 \| 近/远 \| 最少天 \| 最多天 \| 日期段(可空) \| 备注` |
| 主动提醒 | 开关、渠道、账号、联系人 peer、人格 ID、提前分钟、每天上限、安静时段、是否用该人格语气 | 人格 ID 留空 = 宿主当前 Web 人格 |
| 天气 | 城市、经纬度、刷新间隔、预报天数、超时、接口地址 | 默认空；城市名用于显示和定位，取数用经纬度 |

## 生成规则

1. 优先级：固定安排 > 三餐 > 正事 > 旅行 > 运动 > 通勤 > 起床/睡前。高优先级会切开低优先级，例如午饭把 9:00–18:00 切成两段。
2. 空档 ≥ 30 分钟才铺自由安排；单段最多 120 分钟，长空档按 90 分钟切。
3. 同一天、同一套作息的结果稳定（按「日期 + 作息哈希」取爱好和基调）。
4. 睡觉跨零点时，计划末尾到 `24:00`，并记 `sleepAt: 00:30（次日）`。
5. 有预报时按天气改写：降水概率 ≥ 60% 或雨雪雷暴 → 运动加「室内 ·」、户外空档换室内；最高温 ≥ 33℃ 避开午后户外；周末晴好、15–28℃、降水概率 < 30% 时留一段「出去走走」。
6. 假期优先于星期：命中的假期和配置的周末日不排正事；调休上班日即使落在周末也按工作日。
7. 旅行低于固定安排、三餐和正事，高于运动：旅行日占大块时间，三餐把它切开；当天确实有旅行块时移除常规运动。
8. 重复规则先看星期，再看模式：双周以 `@日期` 所在周（周一起算）为基准周；每月第 N 个按该月第几个该星期几算；每月最后按「下周同星期几是否已到下个月」判断；例外日期命中则当天跳过。正事命中法定调休上班日时，优先按工作日生成。
9. 异常日只覆盖当天：生成前把长期配置复制一份临时修改，计划写入 `exception` 元信息；配置与异常原因都参与过期判断，撤销后强制重排恢复。异常记录存在 `data/exceptions.json`，不写回 `config.json`。

## 周复盘口径

- 只统计落盘的 `done / skipped`，未点过的项目保留 `pending`，不会自动算完成。
- 「完成率」= done / 全部可执行项（含 pending）；另给「已处理完成率」= done / (done + skipped)，避免 pending 把曲线压得太低。
- 睡眠和起床/睡前洗漱项不参与完成率；自动铺的自由/家务/休息空档只是填充，也不计入。睡眠趋势取每份计划末尾的 `sleepAt`，跨零点的入睡时间按次日归并后平均。
- 旅行按计划里有 `travel` 的天数计；运动按 `exercise` 项的完成数 / 计划数计。
- 本周按周一至周日；对比上一周同口径，未生成计划的天不计入分母。

## 0.8.0 新增

- 人格日记：按当天日程、天气和穿搭自动生成，默认在睡前洗漱前；支持预设文风和自定义文风/示例；错过时间可在日历页补写，旧日记可编辑、重写、删除。
- 人格隔离读取：`data/journals/<人格目录>/YYYY-MM-DD.json` 按人格分开；`schedule_diary` 只返回当前人格的日记；每轮只注入当天索引。
- 多角色与通用化：不预设人格、模型、城市或本机路径；多角色时必须选写日记的人格，单角色自动使用；生成时间从作息推算，也可固定。

## 0.7.0 新增

- 待办池：`schedule_todo` 工具或日历页管理；今天的空档自动填空（普通待办最多 2 条，「今天必须做」优先）；可钉到指定日期。
- 提醒分级：正事 / 固定安排 / 待办可单独设提前分钟；休息日、节假日和异常日可静音；日历上「稍后」会持久化一条延后提醒，完成或删除条目后自动作废。
- 日历导出：登录后可下载 `calendar.ics`；开启后在本机起一个带 48 位随机令牌的只读订阅服务，手机/电脑日历可直接订阅。服务只读已生成日程，关闭开关立即失效。
- 旅行行程单：旅行块会附交通、住宿、行前清单、预算拆分和坏天气备选；预算与货币在设置页填写，不写死城市。
- 小时级天气：天气子插件取 96 小时逐小时预报；通勤有降水时标注带伞，户外段给出降水最低的窗口，旅行备选日带时间窗。
- 通用化：周起始日可改（影响日历与复盘）；可导入任意 ICS 日历的全天事件作为自定义假期；配置可导出/导入；导出日历支持中文/英文标题和时区。
- 子插件发行：主插件、`schedule/weather`、`schedule/wardrobe` 分开打包；子插件条目依赖父插件，商店会先装主插件。

## 数据与隐私

- `data/config.json`：设置。
- `data/days/YYYY-MM-DD.json`：每天的计划；`keepDays` 之外自动清理。
- `data/exceptions.json`：异常日记录（`{version:1, days:{日期: {kind, note, createdAt}}}`），和计划一起按 `keepDays` 清理。
- `data/todos.json`：待办池，跨天保留；最多 100 条。
- `data/ics.json`：只读订阅服务的随机令牌（不随配置导出）。
- `data/reminders/YYYY-MM-DD.json`：当天提醒记录，用于去重和每日上限。
- `data/journals/<人格目录>/YYYY-MM-DD.json`：人格日记，按人格隔离；不进入 `keepDays` 清理。
- `data/travel.json`：AI 选过的目的地缓存。
- `sub/weather/data/config.json`：天气配置。
- 所有数据只在本机。只有开启 AI 润色时才发送「当天已有安排 + 空档 + 额外要求」；开启 AI 选旅行目的地时只发送日期、假期名称、地点池和旅行偏好。
- 生成人格日记时只发送「当天日程摘要 + 天气 + 穿搭 + 所选文风」，不发送聊天原文；日记不会自动写入宿主核心记忆。
- 天气只把经纬度发给 Open-Meteo，不发送日程、聊天或身份信息。

## 卸载

控制台停用「日程」→ 删除 `plugins/schedule/`（需要连数据一起清就删掉目录里的 `data/`）→ 重启 WhaleLife。

升级时直接覆盖源码即可，`data/` 会被保留。
